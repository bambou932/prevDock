# prevDock

`prevDock` is a small macOS utility that shows Windows 11-style window previews when the pointer hovers over an app icon in the Dock.

`0.1.0` is an early preview release, not a stable 1.0 release. The first public builds support Apple Silicon Macs running macOS 14 or later.

## Install

Homebrew installation is planned through the prevDock tap:

```sh
brew tap bambou932/prevdock
brew install --cask prevdock
```

You can also download `prevDock-0.1.0-arm64.zip` from the GitHub Releases page once the notarized preview release is published.

## How it works

- Reads the Dock item under the pointer with macOS Accessibility APIs.
- Matches the Dock item to a running app by title or Dock item URL.
- Lists the app's visible and AX-discoverable windows through Accessibility, Quartz Window Services, and a remote-token fallback inspired by AltTab.
- Captures visible window thumbnails with SkyLight/ScreenCaptureKit-style window capture paths and displays a floating preview shelf.
- Pins the preview shelf to the Dock item so it does not follow small mouse movements.
- Focuses the clicked preview window with Accessibility before activating the owning app.
- Hides previews immediately while Dock click or context-menu interactions are active.

macOS does not expose an official Dock hover API, so Dock detection depends on Accessibility and can vary a little by macOS version or Dock configuration.

## Build

```sh
./scripts/build.sh
```

The app bundle is written to:

```text
build/prevDock.app
```

## Run

Open `build/prevDock.app`. The app appears in the menu bar as a small icon.

On first launch, grant:

- Accessibility
- Screen Recording

After granting permissions, restart `prevDock` if macOS asks for it.

## Updates

Open the menu bar icon, choose **Settings...**, then use **Update Now...** in the Updates section. prevDock uses Sparkle to check for an update and continue into the download/install flow when an update is available. The Homebrew cask is marked as auto-updating because Sparkle can update the app outside `brew upgrade`.

Automatic update installation is off by default for the preview release. You can enable it in Settings.

## Release

Preview releases use SemVer-style versions before 1.0, such as `0.1.0`, `0.1.1`, and `0.2.0`.

```sh
scripts/release.sh 0.1.0
```

The release script requires:

- a Developer ID Application certificate in the login keychain
- a stored `notarytool` keychain profile named `prevdock-notary`
- the Sparkle EdDSA private key generated by Sparkle's `generate_keys`

It builds, signs, notarizes, staples, zips, updates the appcast, publishes a GitHub pre-release, and updates the Homebrew tap.

## Current limits

- Requires macOS 14 or later.
- Visible on-screen windows get real thumbnails.
- Minimized windows can be listed, but macOS usually cannot provide a live thumbnail for them.
- Live thumbnail refresh is throttled to avoid excessive capture work.

## Dock label note

macOS does not provide a supported API for disabling Dock hover labels. prevDock applies a best-effort startup workaround by backing up `com.apple.dock.plist`, clearing Dock tile `file-label` values, disabling the Dock's recent-apps section, and restarting Dock only during that startup sync. While prevDock is running, it also consumes Dock-strip mouse-move events before Dock can create its native hover label; prevDock's own hover monitor then handles previews and inactive-app labels.
